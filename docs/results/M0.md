## 3. What M1 inherits

- **Remote apps rely on tool descriptions plus the custom instruction**, because none of them passes server instructions. The
  descriptions must be rewritten in a neutral, descriptive voice: ChatGPT flags the current policy-like wording as
  "Suspicious Instruction" (ADR-0104).
- **Saved text must be pronoun-free.** One Claude save produced "His test city…" (ADR-0103).
- **Coding-tool install** (ADR-0109, ADR-0110):
  - **Claude Code:** the plugin, with no deny list.
  - **Codex:** the plugin in the legacy `.codex-plugin/` layout, plus the owner's one-time hook trust.
  - **Cursor:** the plugin for MCP and the rule, plus `~/.cursor/hooks.json` written by `init`. The bundle the Cursor hooks call
    lives under `~/.cursor`, never under `%LOCALAPPDATA%`.
- **Store and storage:** the server uses `node:sqlite` (ADR-0006) and creates `store.db` with mode 0660 (spec-issues #14).
- **Spec issues found in M0:** #1–#21 in [spec-issues.md](spec-issues.md). Open for later milestones: #6, #7 (single anomaly
  monitor), #8, #12, #21.
