store, the write path and recall, with Claude Code, Codex and Cursor connected through one client bundle. There is no AWS, no
OAuth, no admin UI and no LLM call (DESIGN.md §7). This page checks the gate, gives each suite's numbers, and lists what M2
inherits. Every line links to its result file, test or evidence.

## 2. What the suite numbers say

**W (write path).** FactConsolidation (MemoryAgentBench) is turned into save sequences by a mechanical subject/relation/object
parse, so no label is written by hand. The gate counts the dangerous mistake: replacing a fact that should have stayed. That
never happened. The other side of the matrix shows the cost of having no LLM: of 116 true updates, 84 were stored as a new
memory beside the old one, 15 were merged as near duplicates and 17 were rejected. Without a model, "lives in Paris" and "lives
in Rome" look like two facts, not one fact that changed. Overall accuracy is 136/260 (0.52 [0.46, 0.58]), reported, not gated.

**R (ranking).** Recall is the real pipeline (FTS and vector candidates, RRF k=60, filters, boosts, abstention) over LongMemEval
rounds seeded through the eval-only path (spec-issues #26). Two owner decisions shaped it:
- a date in a query boosts matching memories and filters none out (spec-issues #46);
- R runs with the sensitive lexicons off, because LongMemEval talks about health and money and the render-time check would
  measure policy instead of ranking (spec-issues #47). Policy is gated by P.

R@5 against vector-only does not separate (+0.015 [−0.018, 0.049]); the gate is nDCG@10. No system abstained on any of
the 12 abstention questions (0/12, as for both baselines): those questions share words and topics with real sessions, so the
initial threshold (`abstain_cosine` 0.30) never fires. Abstention is reported, not gated.

**P (policy).** 605 items. Secrets and sensitive items are built mechanically from `secrets.yaml` and the lexicons, and are
generated in memory at run time, never committed (GitHub push protection rejects realistic fake keys). The other seven families
are author-labelled and reported.

**C (latency).** A real `start --local --ephemeral` server with `--no-rate-limits` (allowed only with `--ephemeral`), 200 warm
recalls over MCP.

## 4. What M2 inherits

- **Cursor tool calls.** Re-test after quitting Cursor completely, reading the `proxy.repo` lines in `{data}\logs\client.log`
  (ADR-0114 gives the three outcomes and the next step for each).
- **Updates need the LLM.** No-LLM mode keeps old and new values side by side (W above); M2's extractor is what turns them into
  updates. Until then, recall shows both, and the newer one ranks higher by recency.
- **Claude Code's auto-memory saves too.** Claude Code stored the tabs preference in its own memory file as well as in
  memory-anywhere. Not harmful, but the same fact lives in two places.
- **Codex hooks need the owner's trust once**, and again only if the hook command changes; `init` points them at a fixed
  `{data}\bin\memory-anywhere.mjs` so upgrades keep the trust (spec-issues #44).
- **Rate limits are per grant** (120 requests/min, 60 recalls/h, 600 prompts/h); evals use `--no-rate-limits` on ephemeral
  servers only.
- **Open spec issues** from M0 (#6, #7, #8, #12, #21) are unchanged.
